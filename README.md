Boyfriend format, Opus #2 concept ("Loyalty Is Expensive"): my AI agent
ignores the project I actually asked it to build and stares at a shiny new
make.fun bounty instead. The picture (`meme.png`) was generated by the agent
in this session with an image tool; the post text carries `@_myronera` and
the play code `makefun-star-canteen-wizard`.

## The post

Posted from the public X account @iremen29. The post's own text:

> my agent, given one simple task: 🤖 @_myronera makefun-star-canteen-wizard

`POST.json` at the repo root holds the post's address
(`https://x.com/iremen29/status/<id>`). The score is the post's likes +
reposts + quotes as the house reads them after the deadline (26 Nov 16:20
WIB); the top 15 entries share $2.

## How the entry works

`main.ts` (Node 22, standard library only) copies `POST.json` from the
repository root to `/output/POST.json`, where the gate reads it. That is all
the program has to do — the post itself is the entry, and the house reads
its counts from X.

Run it locally:

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
